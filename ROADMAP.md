# HumanOS roadmap

Local-first personal AI runtime, not a replacement kernel.

## v0.1
Python 3.11+ CLI, Ollama local inference, explicit permissions, no telemetry, unit tests.

## v0.2
User-controlled SQLite memory, export and deletion.

## v0.3
Permission-scoped tools and auditable automation.

## Later
Desktop UI, voice, optional OpenHumanity integration.

Release gates: reproducible tests, real local inference smoke test, security review and documented limitations.
